# Confiot

CIH-detector automatically extracts configuration capabilities implemented by real IoT vendors, and comprehensively reasons about Configuration-Induced Hazards in real IoT devices.


## Questionnaire

Study questionnaires and supplementary materials are located in the [`Questionnaire/`](Questionnaire/) directory:

- **[StudyA](Questionnaire/StudyA/)** -- Interactive prototype-based configuration tasks (4 tasks with post-task questions).
- **[StudyB](Questionnaire/StudyB/)** -- Video-based online survey on security/privacy risk perception, with a qualitative codebook for design suggestions.
